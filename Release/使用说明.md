# ReadAcross Dashboard 使用说明

四个 exe 都是独立运行、**不需要安装 Python**。请把 `UpdateDatabase.exe`、`GenerateDashboard.exe`、`IntegrityOpener.exe`、`UpdateAll.exe` 放在**同一个文件夹**里使用。

## 四个 exe 分别做什么

| exe | 作用 | 需要的条件 |
|---|---|---|
| `UpdateDatabase.exe` | 从 PTC Integrity（Windchill RV&S）取数，生成 `output\dashboard.db` | 需 PTC 客户端 + 内网 |
| `GenerateDashboard.exe` | 读 `output\dashboard.db`，生成 `dashboard.html`，并启动 PTC Integrity opener 服务（默认行为） | 无任何要求 |
| `IntegrityOpener.exe` | **只**启动 PTC Integrity opener 服务（监听 `127.0.0.1:8766`），让 dashboard 里的 ID 链接能一键唤起桌面客户端 | 无任何要求 |
| `UpdateAll.exe` | 一键 = 先取数 → 生成网页 → 启动 opener → 自动打开浏览器 | 需 PTC 客户端 + 内网 |

双击运行即可；命令行方式也支持参数（如 `GenerateDashboard.exe --db 某个.db --out 报告.html`），双击 = 零参数默认行为。

> GenerateDashboard.exe / UpdateAll.exe 双击后控制台窗口会**保持开启**——这是新行为，因为它们内置了 opener 服务，关掉窗口就停止服务。需要时 Ctrl+C 退出。

## 文件放哪里（默认布局）

```
任意文件夹\
├── UpdateDatabase.exe
├── GenerateDashboard.exe
├── IntegrityOpener.exe
├── UpdateAll.exe
├── output\            ← UpdateDatabase.exe 自动创建
│   ├── dashboard.db   ← 数据库（唯一数据源）
│   ├── data.xlsx
│   ├── dashboard_manifest.json
│   └── dashboard_schema.json
└── dashboard.html     ← GenerateDashboard.exe 生成，双击即看
```

只想看现有数据的看板 → 双击 `GenerateDashboard.exe` 就够了。
要最新数据 → 双击 `UpdateAll.exe`（或先 `UpdateDatabase.exe` 再 `GenerateDashboard.exe`）。
只想把已经生成的 dashboard 链接到 PTC 客户端 → 双击 `IntegrityOpener.exe`，然后正常打开 dashboard.html。

## PTC Integrity 链接集成（ID 一键唤起桌面客户端）

Details 页面的表格 ID 列是可点击的链接。点一下可以跳到对应 item，但方式取决于浏览器有没有装 Mimecast / 企业 URL Rewriting 之类的拦截扩展。

### 行为对照

| 环境 | 点击 ID 后的行为 |
|---|---|
| 无 PTC 客户端 + 浏览器无拦截 | 直接打开 Web 版 Integrity 页面 |
| 有 PTC 客户端 + 浏览器**无拦截** | 直接唤起 PTC RV&S 桌面客户端打开 item |
| 有 PTC 客户端 + 浏览器**有拦截**（如 Mimecast） | 浏览器派发被改写，客户端报 `Incorrect URL format` |

第三种情况是企业部署里最常见的——浏览器扩展会改写 `integrity://` 这种自定义协议，桌面客户端拿到的是被包装过的 URL，无法解析。

### 解决方式：本地 opener 服务

`IntegrityOpener.exe` / `GenerateDashboard.exe` / `UpdateAll.exe` 任意一个启动后，会在后台开一个本地 HTTP 服务：

- 监听 `127.0.0.1:8766`
- 暴露 `GET /open?url=<URL>`：收到后通过 Windows ShellExecute（`cmd /c start "" "<URL>"`）派发 URL 到 PTC 客户端
- 这一步**完全在浏览器外的进程里发生**，Mimecast 看不到、改不到

dashboard.html 检测到 opener 服务存在后，会把所有 ID 点击**先**通过这个通道派发，绕开浏览器拦截；如果 opener 没启动，会弹一个英文提示框让用户去启动它（同时退回到打开 Web 版页面作为兜底）。

### 使用步骤（装了 PTC 客户端 + 有 Mimecast 拦截的环境）

1. 双击 `IntegrityOpener.exe`（或 `GenerateDashboard.exe` / `UpdateAll.exe`），控制台窗口留着别关。
   ```
   [opener] listening on http://127.0.0.1:8766/  (Ctrl+C to stop)
   ```
2. 用任意方式打开 `dashboard.html`（浏览器、文件管理器双击、内网 web 服务都行）。
3. 在 Details 页面点任意 ID → PTC RV&S 客户端自动唤起并打开对应 item。

关掉 `IntegrityOpener.exe` 控制台窗口就停服务，下次再点 ID 会弹英文提示框告诉你重新启动它。

## 取数（UpdateDatabase.exe / UpdateAll.exe）的前提

1. 电脑上装有 **PTC Integrity / Windchill RV&S 客户端**，且 `im` 命令在 PATH 上（命令行敲 `im` 有响应即可）
2. 能访问服务器 `skobde-mks-im.kobde.trw.com:7001`（内网/VPN）
3. **首次使用先在命令行运行一次 `im connect --hostname=skobde-mks-im.kobde.trw.com --port=7001`**，按提示登录，客户端会记住凭据；之后 exe 取数不会再问密码

以上是 PTC 客户端本身的要求，exe 无法替代登录。

## 怎么确认取数成功

控制台最后会打印四个 `完成: ...` 路径；也可以打开 `output\dashboard_manifest.json`，看 `counts`（ecr / work_item / action / build 的条数）是否合理、`generated_at` 是否是刚才的时间。

## 常见问题

- **双击 GenerateDashboard.exe / IntegrityOpener.exe / UpdateAll.exe 后窗口不消失**：正常——这三个 exe 启动后会保留控制台窗口跑后台服务。需要退出时 Ctrl+C 或直接关窗口。
- **点 ID 弹 "PTC Integrity Opener is not running"**：没启动 opener 服务，双击 `IntegrityOpener.exe` 后再点一次。
- **点 ID 唤起 PTC 客户端但弹 `Incorrect URL format`**：浏览器扩展比 opener 更早拦截。确认 opener 控制台窗口还在、且 dashboard.html 是从 opener 启动之后才刷新的；如果还不行，把 `127.0.0.1:8766` 加到企业 URL Rewriting 白名单。
- **双击后窗口一闪而过（取数类 exe）**：正常情况下结束前会停留（"按回车键退出"）。若直接消失，用命令行运行一遍看报错。
- **杀毒软件报警/exe 消失**：PyInstaller 打包的程序偶有误报，请加白名单或找回被隔离的文件。
- **`连接 PTC Integrity 失败`**：检查上面"取数的前提"三条（客户端、网络、凭据）。
- **`DB not found`（GenerateDashboard.exe）**：先运行一次 `UpdateDatabase.exe`，并确保两个 exe 在同一文件夹。
- **`im exportissues 成功返回但未生成文件`**：多为查询无结果或权限不足，确认账号能看到根 ECR（如 8555340，完整清单见 `output\dashboard_manifest.json` 对应 DB 的 `metadata.root_item_ids`）的数据。
