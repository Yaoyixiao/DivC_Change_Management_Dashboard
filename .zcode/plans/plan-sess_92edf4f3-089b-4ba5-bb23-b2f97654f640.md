# ECR 透视树 Sheet 实现计划

## 目标

在 `data.xlsx` 中新增一个 **"ECR Tree"** sheet：按 ECR 层级缩进展示 ECR → Work Item(L0/L1/L2) → Action / Build，利用 **Excel 大纲分组（outline grouping）** 实现原生的 +/− 按层级折叠展开（openpyxl 无法创建真正的 PivotTable 对象，大纲分组是"类似透视表"的标准实现），并对配置指定的数值列做子树 sum 汇总（如 ALM_Planned Effort）。

## 透视树 Sheet 规格

- **Tab 顺序**：Items, **ECR Tree**, Edges, Metadata。
- **列**：`ID, Kind, Summary, State, Subtree Items` + 每个汇总指标两列：`{字段别名}`（自身值）与 `{字段别名} Subtotal`（自身+全部后代的和；叶子行两者相等）。
- **行序与层级**：按 ECR（Items 顺序）逐棵深度优先输出：ECR 行 → 其 Work Item 子树（L0→L1→L2，子节点按发现顺序）→ Action 组 → Build 组。
- **折叠**：行 `outlineLevel` = 树深度（ECR=0，L0=1，L1=2，L2=3，Action/Build=1）；`outlinePr.summaryBelow=False` 使 +/− 出现在父行上；ECR 行与 Summary 列按深度加 Excel 缩进。
- **汇总行**：表头下第 2 行为加粗的 `TOTAL` 行（= 各 ECR Subtotal 之和）；每个 ECR 行加粗。
- **数值**：Effort 值均为纯数字字符串 → `float` 解析（去千分位逗号），解析失败/空串按 0 计入 Subtotal；自身列可解析则写数值，否则原样。

## 汇总列配置（按你的选择：配置化）

- `ECR_Config.xlsx` 新增**可选** sheet `Pivot`：单列、表头 `Field`，列出要做 sum 的原始字段名（与 Data_Field 同风格）。**我会直接在你的 src/ECR_Config.xlsx 里加上这个 sheet**，预填当前有数据的 4 列：`ALM_Planned Effort`、`ALM_Remaining Effort`、`ALM_Rollup Planned Effort`、`ALM_Rollup Actual Effort`（`rough_effort_estimation` 全空不预填）。
- 校验：Pivot 里的每个字段必须存在于 Data_Field 字段表，否则报错；去重保序。
- **缺省**：没有 Pivot sheet 时 = `ALM_Planned Effort`（若字段表里有它）；PTC 自带的 `rollup_planned_effort` 列正好可以和我们自算的 Subtotal 互相印证。

## 树构建语义（写进代码注释与 Handoff）

1. 子树从 `edges` 构建：`work_items` 边给出 ECR→L0 与 WI→子 WI，`actions`/`work_item_for` 边只从 ECR 出发（现契约已保证）。
2. **每个 ECR 子树内节点去重**：同一 WI 在该 ECR 子树内有多个父级时，只挂在**首条路径**下（发现序=最短路径，与 level 语义一致），汇总不重复计数。
3. 同一节点被**不同 ECR** 引用时在两棵树里各出现一次（各按自身子树汇总）；TOTAL 行等于各 ECR Subtotal 之和，因此共享节点在 TOTAL 中会被计多次——列内一致性优先，Handoff 中注明此口径。
4. 无子级的 ECR：叶子行，Subtotal = 自身值，Subtree Items = 1。
